## 💫 About Me

I'm a full-stack developer and GenAI tinkerer passionate about building solutions that **actually solve problems**. I work across the entire tech stack:

- 🌐 Crafting responsive React UIs
- 🔧 Developing scalable APIs
- 🤖 Building multi-agent GenAI systems
