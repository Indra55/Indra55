# 💫 About Me:
Hey, I'm Hitanshu — a full-stack developer and GenAI tinkerer with a love for building things that *actually solve problems*. I work across the stack, from React UIs and scalable APIs to multi-agent GenAI systems and backend infrastructure in Go or Node.

Always curious, always shipping. Let’s build something cool.
